## Эмулятор процессора (одноадресная архитектура)

Этот проект — учебный эмулятор CPU с фон-неймановской архитектурой и одноадресными командами, 32-битной разрядностью, 8 регистрами общего назначения и стеком. Включает:
- ядро (ALU, память, регистры, флаги, декодер, CPU),
- простой ассемблер и загрузчик программ,
- консольные демонстрации,
- графический интерфейс на Tkinter с пошаговой отладкой, просмотром памяти и исходного текста.

### Быстрый старт

- Консольные демо:
  - Запуск: `python -m cpu_emulator_oneadress.main`
  - Демонстрации: базовые арифметические операции, работа с памятью

- GUI (Tkinter):
  - Запуск: `python -m cpu_emulator_oneadress.main --gui`
  - Возможности: загрузка ASM из файла, Step/Run/Pause/Reset, просмотр регистров/флагов/PC/IR, память (Bytes/Words), подсветка текущей инструкции

### Структура проекта

- cpu_emulator_oneadress/
  - cpu/
    - alu.py (Арифметико-логическое устройство)
    - cpu.py (Основной цикл процессора)
    - decoder.py (Декодер инструкций)
    - flags.py (Работа с флагами состояния)
    - instruction_set.py (Набор инструкций процессора)
    - memory.py (Управление памятью)
    - program_loader.py (Загрузчик программ)
    - registers.py (Работа с регистрами)
  - gui.py (Графический интерфейс)
  - main.py (Точка входа)
  - tests/ (Тесты)


Минимальный путь погружения:
1) Посмотрите `cpu/instruction_set.py` — набор опкодов и формат команд
2) Загляните в `cpu/decoder.py` — как команды превращаются в структуру `Instruction`
3) Откройте `cpu/alu.py` и `cpu/flags.py` — семантика операций и обновление флагов
4) Пройдитесь по `cpu/cpu.py` — Fetch–Decode–Execute, вызовы ALU и память
5) Для практики запустите GUI (`--gui`) и "прошагайте" программу

### Архитектура и модель

- 32-битные регистры: R0-R7; SP доступен как R8, есть PC (program counter) и IR (последняя команда)
- Память: по умолчанию 256 KiB, выровненные 32-битные слова (адрес кратен 4)
- Одноадресная архитектура: команды работают с одним явным операндом
- Формат команд: определяется в instruction_set.py

### Ассемблер (упрощённый)

Поддерживаются базовые мнемоники (регистр R0..R8, где R8 — SP), константы #N или #0xHEX.

Примеры одноадресных команд:
LOAD R1 # Загрузить значение в R1
ADD [A] # Прибавить значение из памяти к аккумулятору
STORE R2 # Сохранить аккумулятор в R2
JMP 100 # Переход к адресу 100
HALT # Остановка


### GUI: как пользоваться

- Управление:
  - Load ASM… — загрузка файла с мнемониками
  - Reset, Step, Run, Pause — управление выполнением
  - Hz — частота при Run
  - View: Bytes/Words, Goto PC

- Окна:
  - Registers/Flags/PC/IR/Cycles — текущее состояние
  - Memory — просмотр памяти в разных форматах
  - Program (ASM) — исходные строки с адресами, подсветка текущей инструкции

### Расширение/изменения

- Добавить новые опкоды: дополните `instruction_set.py`, реализуйте логику в `cpu.py` и `alu.py`
- Изменить форматы команд — расширьте `Instruction` и `InstructionDecoder`
- Дополнительные виды памяти — меняйте `Memory` и параметры CPU
